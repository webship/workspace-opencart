# @webship.co/workspace-opencart

OpenCart, the open-source shop, for the [Webship Workspace](https://github.com/webship/workspace) dashboard: a builder
that makes a real OpenCart shop in containers with its demo data, its tool, the default accounts (the administration's
and a customer), the OpenCart step pack wired into the workspace's testing setup, and its AI items.

The builder, the tools, the tests and CI come with the first release, `1.0.0`.
